# 002.CONFIGURATION.md

이 문서는 agentoscope가 OpenCode Plugin에 쓰는 설정을 정합니다. Plugin의 구현 방안은 [OpenCode Plugin](001.OVERVIEW.md)을, 용어는 [Glossary](../../../001.model/002.GLOSSARY.md)를 따릅니다.

## 원칙

- Plugin은 OpenCode가 쓰는 환경 변수와 설정 파일을 읽지 않습니다. 그 값들은 OpenCode 프로세스의 환경에 있는 것이며, Daemon 프로세스에 같은 값이 있다는 보장이 없습니다. Daemon의 환경에 우연히 있는 값을 따르면 사용자가 의도하지 않은 DB를 읽게 됩니다.
- OpenCode의 설정 때문에 Plugin이 따로 알아야 하는 값은 이 문서의 설정으로 받습니다.
- 설정은 Daemon이 시작할 때 한 번 읽습니다. 값을 바꾸면 Daemon을 다시 시작해야 합니다.

## 환경 변수

| 변수 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `AGENTOSCOPE_OPENCODE_DB` | string | `<홈 디렉터리>/.local/share/opencode/opencode.db` | 수집할 OpenCode DB 파일의 절대 경로 |

### `AGENTOSCOPE_OPENCODE_DB`

| 값 | 처리 |
|---|---|
| 없거나 빈 문자열 | 기본값을 씁니다. OpenCode 정식 배포본을 환경 변수와 설정 없이 실행했을 때의 위치입니다. |
| 절대 경로 | 그 경로의 DB를 수집합니다. |
| 절대 경로가 아님 | 로그를 남기고 수집하지 않습니다. |

OpenCode가 기본 위치가 아닌 곳에 DB를 기록하게 했다면, `opencode db path`로 실제 경로를 확인해 이 값에 넣습니다. 파일이 아직 없으면 [Trigger](001.OVERVIEW.md#trigger)의 30초 주기로 다시 확인합니다.

## 결정되지 않은 사항

- DB 여러 개(채널별 DB 등)를 함께 수집할지
- 이 설정을 환경 변수 대신 Daemon 설정 파일([Client Adapter Daemon 구현](../../007.CLIENT_ADAPTER_DAEMON.md#설정))로도 받을지
