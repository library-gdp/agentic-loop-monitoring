# 002.MESSAGE_CONVENTION.md

이 문서는 [Agent Logging Protocol](../001.model/004.AGENT_LOGGING_PROTOCOL.md) 버전 `1`의 메시지 규약을 정합니다. 메시지를 실어 나르는 방식은 [Transport](003.TRANSPORT.md)를 참고하세요. 메시지의 필드와 규칙은 model 문서를 따르며, 이 문서는 바꾸지 않습니다. 용어는 [Glossary](../001.model/002.GLOSSARY.md)를 따릅니다.

## 메시지 규약

모든 메시지는 UTF-8 JSON 객체입니다. 필드 이름은 [Agent Logging Protocol](../001.model/004.AGENT_LOGGING_PROTOCOL.md)과 [Domain Model](../001.model/003.DOMAIN_MODEL.md#session-log-event)의 필드 이름을 그대로 씁니다. 시각은 RFC 3339 형식의 string으로 쓰며 시간대를 포함합니다.

이 규약은 Daemon과 Main Server가 다른 프로세스일 때 씁니다. [프로세스 내 호출](003.TRANSPORT.md#프로세스-내-호출)에서는 같은 필드를 가진 객체를 직렬화하지 않고 넘깁니다.

### Transport Unit

```json
{
  "protocol_version": 1,
  "transport_unit_id": "0f7c2d3e-5a41-4b8e-9d0a-2c6f1e7b9a10",
  "source": {
    "agent": "claude-code",
    "plugin_version": "0.1.0",
    "host": "dev-laptop"
  },
  "session": {
    "id": "9b2e...",
    "cwd": "/home/user/my-project"
  },
  "agent": {
    "id": "a0be...",
    "parent_id": "9b2e..."
  },
  "turn": {
    "id": "a0be...:12",
    "position": 3
  },
  "events": []
}
```

위 예시는 Subagent의 Transport Unit입니다. Main Agent의 Transport Unit에서는 `agent.parent_id`를 뺍니다. `events`에는 레코드 하나에서 나온 Session Log Event가 들어갑니다.

### Ack

성공:

```json
{
  "protocol_version": 1,
  "transport_unit_id": "0f7c2d3e-5a41-4b8e-9d0a-2c6f1e7b9a10",
  "status": "accepted"
}
```

거절:

```json
{
  "protocol_version": 1,
  "transport_unit_id": "0f7c2d3e-5a41-4b8e-9d0a-2c6f1e7b9a10",
  "status": "rejected",
  "retryable": true,
  "error": { "code": "unavailable", "message": "storage is not ready" }
}
```

JSON으로 해석할 수 없는 Transport Unit은 `invalid_transport_unit`으로 거절합니다.
