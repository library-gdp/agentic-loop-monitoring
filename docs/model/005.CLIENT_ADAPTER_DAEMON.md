# 005.CLIENT_ADAPTER_DAEMON.md

이 문서는 Client Adapter Daemon(이하 Daemon)의 동작을 설명합니다. 시스템 안에서 Daemon이 차지하는 위치는 [System Architecture](000.SYSTEM_ARCHITECTURE.md)를, 용어는 [Glossary](001.GLOSSARY.md)를 참고하세요.

## 구성 요소

| 구성 요소 | 역할 |
|---|---|
| Plugin | 에이전트마다 하나씩 둡니다. 자신이 정의한 Trigger와 수집 방식에 따라 Session Log를 수집하고 Session Log Event로 변환한 뒤, 레코드 하나씩 Transport Unit으로 Daemon에 넘깁니다. [Plugin Specification](004.PLUGIN_SPEC.md)을 따릅니다. |
| Transport Client | 설정된 Transport로 Main Server에 Transport Unit을 보내고 Ack를 받습니다. [Agent Logging Protocol](003.AGENT_LOGGING_PROTOCOL.md)을 따릅니다. |

## 실행

Daemon은 에이전트가 실행되는 머신에 상주합니다.

- Daemon은 시작할 때 설정에서 활성화한 Plugin을 시작합니다.
- Daemon은 Session Log를 직접 수집하지 않습니다. 언제 수집할지(Trigger)와 어떻게 수집할지는 Plugin이 정합니다([Plugin Specification](004.PLUGIN_SPEC.md#plugin이-정의하는-것) 참고).
- Daemon은 Plugin이 Session Log를 어디까지 수집했는지 기록하지 않습니다. 이것도 Plugin이 맡습니다.
- Daemon은 Session Log Event를 묶거나 나누지 않습니다. Transport Unit에 무엇을 담는지는 [Plugin Specification](004.PLUGIN_SPEC.md#transport-unit)을 참고하세요.

## Session Log Event 전송

### Transport Unit 받기

Plugin은 Session Log의 레코드 하나에서 나온 Session Log Event를 Transport Unit 하나로 Daemon에 넘깁니다. Daemon은 넘겨받은 Transport Unit을 그대로 보냅니다.

- Daemon은 Transport Unit을 합치거나 나누지 않습니다.
- Session ID, Agent ID, 부모 Agent ID, 작업 디렉터리, Turn 정보(`turn.id`, `turn.position`)와 Session Log Event는 Plugin이 넘긴 값을 그대로 담습니다. `protocol_version`, `transport_unit_id`, `source`는 Daemon이 채웁니다.

### 보내기

Daemon은 Transport Unit을 하나씩 보냅니다. Transport Unit을 보낸 뒤에는 Ack를 받거나 타임아웃이 날 때까지 기다리며, 그동안 다른 Transport Unit을 보내지 않습니다. 여러 Plugin이 넘긴 Transport Unit은 넘겨받은 순서대로 보냅니다.

### Ack 처리

| 결과 | 다음 동작 |
|---|---|
| 성공 Ack | 다음 Transport Unit을 보냅니다. |
| 재시도 가능한 실패: 연결 실패, 전송 실패, Ack 타임아웃, `retryable`이 `true`인 거절 Ack | 정해진 횟수만큼 간격을 늘려가며 같은 Transport Unit을 다시 보냅니다. 모두 실패하면 로그를 남깁니다. |
| 재시도할 수 없는 실패: `retryable`이 `false`인 거절 Ack | 로그를 남기고 Transport Unit을 버립니다. |

## 설정

| 항목 | 설명 |
|---|---|
| Transport | 사용할 Transport의 종류와 주소입니다. |
| Ack 타임아웃 | Transport Unit을 보낸 뒤 Ack를 기다리는 최대 시간입니다. |
| 재시도 횟수와 간격 | 재시도 가능한 실패에서 같은 Transport Unit을 다시 보내는 횟수와 간격입니다. |
| 사용할 Plugin | 활성화할 Plugin의 에이전트 id 목록입니다. |

## 로그

Daemon은 자신의 로그 파일에만 기록하며, 에이전트에는 아무것도 출력하지 않습니다. 다음 경우에는 로그를 남깁니다.

- Plugin이 레코드를 해석하지 못하고 건너뛴 경우
- 재시도 가능한 실패와 재시도를 모두 실패한 경우
- 재시도할 수 없는 거절로 Transport Unit을 버린 경우

## 결정되지 않은 사항

- 재시도를 모두 실패한 Transport Unit을 나중에 다시 보내는 방법
